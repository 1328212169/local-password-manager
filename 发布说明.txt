## 📥 安装说明

### 方式一：直接运行（推荐）
1. 解压 `密码管理器1.2.4.zip` 到任意目录
2. 双击 `密码管理器.exe` 运行
3. 首次使用需设置主密码

### 方式二：从源码运行
```bash
git clone <仓库地址>
pip install -r requirements.txt
python main.py
```

## ⚠️ 注意事项

1. **数据安全**：所有密码数据本地加密存储，建议定期备份
2. **主密码**：请牢记主密码，虽然可以通过邮箱重置，但会丢失历史数据
3. **邮箱绑定**：强烈建议绑定邮箱用于密码重置
4. **备份建议**：定期导出数据库到安全位置
5. **数据兼容**：本版本数据文件完全兼容 v1.2.3，可直接升级使用
